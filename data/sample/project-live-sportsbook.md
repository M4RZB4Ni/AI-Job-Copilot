# Project: Live sportsbook mobile platform

## Context
A live sportsbook app on the App Store and Play Store with 50K+ monthly active users and a 4.5-star Play Store rating. Role: Senior Mobile Engineer (Flutter/Android) at a live sportsbook company, owning the mobile platform, January 2024 to present, remote. Work spans Android, iOS, and Web teams through architecture-focused code reviews.

## Actions
- Built wallet and live-betting features over a SignalR real-time connection, keeping 50K+ concurrent users in sync during peak live events.
- Designed an offline-first caching layer so the app keeps working through network drops during live events.
- Raised automated test coverage and removed unnecessary UI rebuilds to stabilize releases.
- Ran 400+ architecture-focused code reviews across Android, iOS, and Web.
- Reworked the Azure DevOps CI/CD pipeline to speed up releases.
- Integrated Adyen, Apple Pay, and Google Pay with biometric authentication for secure, high-volume transactions.
- Used Firebase Remote Config, Crashlytics, and Analytics for feature flags and production health monitoring, keeping the app compliant with gambling-regulatory requirements.

## Results
- Backend load reduced by 50%.
- Automated test coverage up 60%, with fewer crash-related support tickets.
- Release cycles 20% faster.
- App grew to 50K+ monthly active users with a 4.5-star Play Store rating.

## Tech
Flutter, Dart, SignalR, Firebase (Remote Config, Crashlytics, Analytics), Azure DevOps, Adyen SDK, Apple Pay, Google Pay, biometric authentication
