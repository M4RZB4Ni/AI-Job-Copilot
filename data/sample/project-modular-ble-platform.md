# Project: Modular Flutter platform with native BLE bridges

## Context
Enterprise and consumer mobile apps built in Flutter at a UK product studio. Role: Lead Mobile Developer, June 2022 to December 2023, remote, leading a team of 6 senior mobile engineers. The project later won an international design award (2025).

## Actions
- Designed the modular architecture used across the apps.
- Built an offline-first module on Firebase and local persistence.
- Wrote native bridges and platform channels connecting Flutter to Kotlin for BLE and hardware communication, plus biometric authentication, securing interactions across hundreds of connected devices.
- Tightened code review and onboarding standards across the team.
- Set up GitHub Actions CI/CD with automated unit and integration testing across multiple production apps.
- Shipped bi-monthly production releases alongside backend, QA, and product.

## Results
- Backend dependency cut by 50%, with 99.9% uptime in low-connectivity conditions.
- Post-release defects down 30%.
- Faster feature delivery across enterprise and consumer apps.
- Less manual deployment effort, with regressions caught before release.

## Tech
Flutter, Dart, Kotlin, platform channels, BLE, biometric authentication, Firebase, local persistence, GitHub Actions
