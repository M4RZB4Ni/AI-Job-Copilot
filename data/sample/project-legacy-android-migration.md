# Project: Legacy Android migration and modular rebuild

## Context
A large-scale Android and iOS app at a UK software agency. Role: Lead Mobile Developer (Flutter/Android), June 2021 to May 2022, remote, directing a team of 6 engineers.

## Actions
- Rebuilt the app on a modular architecture.
- Migrated a legacy Android codebase to Clean and modular architecture.
- Designed reusable UI components and modular systems.
- Ran 200+ structured code reviews and set architectural governance adopted across the 6-person team.
- Connected the app to REST, GraphQL, and real-time APIs through reactive async streams.
- Built a 75-test automated end-to-end suite.

## Results
- Feature build time cut by 50%.
- Development speed tripled for the team, with less code duplication.
- 80% of technical debt paid down, easing long-term maintenance.
- Post-deployment defect escape rate cut by 10%.
- Better sync reliability and UI responsiveness.

## Tech
Flutter, Kotlin, Android, Clean Architecture, modular architecture, REST, GraphQL, reactive async streams, end-to-end testing
